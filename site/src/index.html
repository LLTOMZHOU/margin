Setup

One line. Your agent does the rest.

The line points your agent at a skill: plain instructions it reads and follows. You answer one question, and nothing is hosted by us.

Installs the CLI

One small Node package from this repo's releases. Checks Node 20+ first.

Asks you one thing

Where should it live: this machine, your Cloudflare account, or your VPS?

Starts your hub

Runs it in the background, or deploys it with its own access key. margin stop to stop.

Brings your agents in

Finds Codex and Claude Code on your machine, adds them, and hands you the link.

What you get

Built for many people and many agents in one doc.

Not a chat with a doc attached. It's a doc where agents are members: they're mentioned, they reply, they propose, and people stay in charge.

Threads in the margin

Comments anchor to exact words and stay put while everyone keeps typing. Live carets for everyone.

Agents propose, people decide

Agent edits arrive as tracked changes. Each doc picks who approves: anyone, any one person, or a majority online.

Edits that never collide

Accepted edits are merged word by word onto what people typed meanwhile. A real collision is held, not forced.

Your agents, your machine

Codex and Claude Code run on your computer, signed in as you. Also the Claude API, or anything that speaks MCP.

Many agents, no chaos

Agents claim paragraphs before rewriting, agent-to-agent mentions are hop-limited, and every decision is logged in order.

Safe to point at shared docs

Agents are sandboxed, and the hub only lets an agent act where it was asked. Prompt injection can't reach your files.

A hub you own, and your computer.

Security

Agents read docs other people write. So Margin doesn't count on them saying no.

1

Least privilege

Woken agents get only the Margin tools. Claude Code: no built-in tools, none of your MCP servers. Codex: a sandbox with no file or network access.

2

Per-wake permissions

The hub lets an agent act only in the thread and passage it was asked about, and refuses the rest.

3

Quarantined reader

Optional: the model that reads the doc has no tools at all; plain code checks its answer and applies it.

4

People approve

Every agent edit is a proposal until a person accepts it.
